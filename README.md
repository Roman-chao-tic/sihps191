# Smaran Caregiver — Dementia Memory & Cognitive Care Prototype

A frontend-only React/Vite prototype inspired by the problem statement:

**“AI-Based Cognitive Gaming and Memory Assistance Platform for Elderly Dementia Patients in the North Eastern Region (NER)”**

## What is included

- Elderly-friendly dashboard
- Daily cognitive game cards
- Memory moments / memory book preview
- Daily reminders
- Care-circle / caregiver area
- Responsive mobile navigation
- Calm, accessible visual language
- No backend, authentication, database or Vercel configuration

## Run locally

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Easy future changes

Most sample content is in:

`src/data/problemData.js`

Change names, games, reminders, memories and caregiver information there.

Later, that same file can be replaced with API/database data while the UI components remain mostly unchanged.
